What the receipt proves

A valid signature authenticates the issuer’s record against a separately trusted public key. It does not prove output correctness, complete observation or absence of escape. Most containment categories are inferred from untrusted program output.

Run npm run demo -- --competition on the prepared Linux deployment to collect actual receipts and a pass/fail report.
