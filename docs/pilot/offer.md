# Private pilot offer — draft for customer discussion

## Offer

Four-week engagement for one AI product team and one Python CSV-analysis workflow in one dedicated environment. Proposed starting price: USD 4,500, 50% at agreement and 50% on delivery against written acceptance criteria. This is a pricing experiment, not a validated market rate. The delivery clock starts after prerequisites and required safety gates are met.

Includes integration assistance capped at 20 engineering hours, one agreed execution policy, synthetic-data demonstration, agreed control tests, an execution evidence export and a final handover. Customer provides an integration owner and technical reviewer. Specify region, inference provider, data categories and approved data flows before using customer files.

Compute and model usage are separately itemised and capped by agreement; pause work before exceeding the cap. External security assessment is separately scoped and priced. No unlimited support, custom agent building or implied certification. Sensitive/regulated data requires additional scoping and a suitability decision.

Before signing, confirm delivery costs and margin. Pricing worksheet: pilot revenue minus engineering hours × internal hourly cost, infrastructure, model charges, external assessment allocation and support reserve. Reduce scope or reprice if the result does not support the business.

## Proposed recurring offer

Test USD 1,000/month plus capped infrastructure/model usage for the same dedicated workflow. Include up to two support hours/month during agreed business hours, routine maintenance and evidence export. State incident response expectations in the agreement; do not promise 24/7 support or an uptime SLA before staffing it. Expansion is a separate quote.

## Acceptance criteria to complete with buyer

- Named input fixture and independently calculated expected output; buyer approves correctness tolerance.
- Agreed network/write/runaway scenarios fail as expected, with trusted observations distinguished from inferred classifications.
- Unauthorised API requests fail; resources are scoped to the authorised customer.
- Receipt retrieval, retention/deletion and shutdown procedures work as documented.
- Record integration hours, p95 latency over an agreed workload, execution/model cost and reviewer findings; set numeric targets before starting.

Acceptance does not certify that escapes are impossible or all generated answers are correct. Address unresolved critical security findings before customer-data execution.

## Discovery questions

1. What generated code runs today, on whose files, and in which environment?
2. What stopped the most recent customer deployment or security review?
3. What does your current solution cost in engineering and operations?
4. Who approves data processing and who controls the budget?
5. What must a four-week pilot demonstrate for you to pay and continue?
6. What alternatives are you considering, and why would you switch?

Record actual answers, deployment deadline, purchasing process, data constraints and next step. Do not equate interest or a free demo with demand.
